# Invocal releases

Release downloads for Invocal — source is private.

- **Download:** the latest DMG is on the [Releases page](https://github.com/michaelzizz/invocal-releases/releases/latest).
- **Automatic updates:** the app checks `appcast.xml` in this repository (served at
  `https://michaelzizz.github.io/invocal-releases/appcast.xml`). Every download is signed with a Developer ID,
  notarized by Apple, and its update is signed with Invocal's own update key.

This repository holds only release files and the update feed. Please don't open pull requests here.
